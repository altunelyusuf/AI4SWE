# AI4SWE

Open-access repository for AI for Software Engineering (AI4SE), volume 2 of the AI4X series.

| Folder | What it is |
|---|---|
| `ai4se/` | The AI4SE ontology, edition 5.0.0: one T-Box, one A-Box, one SHACL file, with the findings register that says what was repaired and what is still open. Start with `ai4se/README.md`. |
| `oe-method/` | The OE Method package (version 3.31.0) that governs how the ontology is structured and checked, copied unchanged from its source. Start with `oe-method/README.md`. |
| `ai4se-sources/` | The book and ontology files as received, stored byte for byte by an earlier step. Not part of the ontology package; start with `ai4se-sources/README.md`. |
