## 🚀 QUICK START GUIDE

### Step 1: Load Ontology (5 minutes)

```bash
# Start Apache Jena Fuseki
docker run -d -p 3030:3030 stain/jena-fuseki

# Load ontology files
for file in AI4SE_Ontology_v5_0_*.ttl; do
  curl -X POST \
    -H "Content-Type: text/turtle" \
    --data-binary @$file \
    http://localhost:3030/ai4se/data
done
```

### Step 2: Install Python Client

```bash
pip install rdflib SPARQLWrapper

# Save client code from Phase 9 as ai4se_client.py
python -c "from ai4se_client import AI4SEOntologyClient; \
           client = AI4SEOntologyClient(); \
           print(f'Companies: {client.find_turkish_companies()}')"
```

### Step 3: Run Sample Queries

```bash
# Install CLI tool
pip install click

# Run queries
python ai4se-cli.py companies
python ai4se-cli.py tools
python ai4se-cli.py roi
```
