### Step 1: Download Files
All files available in `/mnt/user-data/outputs/`:
- Core ontology (.ttl files)
- Documentation (.md files)
- All previous project files

### Step 2: Load into Triple Store
```bash
# Start Apache Jena Fuseki
docker run -p 3030:3030 stain/jena-fuseki

# Load ontology files
curl -X POST \
  -H "Content-Type: text/turtle" \
  --data-binary @AI4SE_Ontology_v5_0_HYBRID_BASE.ttl \
  http://localhost:3030/ai4se/data

# Repeat for PHASE2_ENRICHMENT.ttl and PHASE3_RELATIONSHIPS.ttl
```

### Step 3: Query with SPARQL
```sparql
# Find Turkish fashion retail classes
SELECT ?class ?definition WHERE {
    ?class :supportsDomain :FashionRetailDomain ;
           skos:definition ?definition .
}

# Find tools used by Trendyol
SELECT DISTINCT ?tool WHERE {
    ?class :fashionRetailExample ?example ;
           :usesTool ?tool .
    FILTER(CONTAINS(?example, "Trendyol"))
}

# Find all security testing techniques
SELECT ?technique WHERE {
    ?technique rdfs:subClassOf* :SecurityTesting .
}
```

### Step 4: Explore Documentation
1. Start with [PHASE4_BOOK_MAPPING.md](computer:///mnt/user-data/outputs/AI4SE_Ontology_v5_0_PHASE4_BOOK_MAPPING.md) for navigation
